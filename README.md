# CrazyPrice

A Vue/Vuetify prototype for browsing local offers and discounts. This repository is kept as part of my career history: the application was developed during an internship in 2020–2021.

## What is included

- an offer catalogue built from reusable Vue components;
- expandable offer summaries and detailed cards;
- ratings, opening hours, and discount information;
- a map-style search header;
- routed home, about, and login views;
- form validation and password-visibility controls.

## Technology

- Vue 2
- Vue Router 3
- Vuetify 1
- Vue CLI 3
- JavaScript and Stylus

## Run locally

```bash
npm install
npm run serve
```

The project uses dependencies from its original development period. A compatible legacy Node.js environment may be needed.
